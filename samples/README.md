# A2UI Labs Samples

This directory hosts runnable samples, prototypes, and integration experiments exploring new A2UI use cases, client platforms, and agent workflows.

## Sample Structure

Each sample is organized in its own sub-folder with a dedicated `README.md` containing:

- **Overview**: Description of what the sample demonstrates and which A2UI protocol features it uses.
- **Prerequisites**: Required SDKs, API keys, or tools.
- **Running the Sample**: Step-by-step commands to build, run, and test.

## Guidelines

- Keep samples focused on demonstrating specific integrations or developer patterns.
- Follow the repository code quality, license header, and formatting conventions.

## Available Samples

- [`flutter-starter`](./flutter-starter/): Starter project for building A2UI client applications with Flutter.
- [`typescript-starter`](./typescript-starter/): Starter project for building A2UI client applications with TypeScript and Node.js.
