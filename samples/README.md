# Samples

End-to-end sample applications that pair an A2UI client with an agent backend.

Each sample lives in its own directory and is independent of the others. It
keeps its own dependencies, lockfiles, tests, and formatting configuration, so
samples can use different languages, frameworks, and tool versions.

Each sample's README explains:

1. What the sample shows.
2. How to install and run it, including how to configure a model or agent
   backend.
3. The terms of service of any external service the sample calls.
