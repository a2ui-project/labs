# A2UI Labs

Starter projects and tools for [A2UI](https://a2ui.org).

| Folder                | Content                         |
| --------------------- | ------------------------------- |
| `typescript-starter/` | TypeScript starter project      |
| `flutter-starter/`    | Flutter starter project         |
| `plugin/`             | Gen UI plugin for coding agents |

The agent skills in `.agents/skills` and some configuration files come from the latest
`main` of the A2UI repository, which is a git submodule at `third_party/a2ui`.
To fetch it or update it, run:

```bash
git submodule update --init --remote
```
